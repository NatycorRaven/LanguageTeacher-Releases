## 能体验什么

当前为**本地记忆基础开发版**：选择本地测试档案和英日韩语言分区、创建任务、保存自己的练习发言、恢复最近会话、查看本地上下文预览。载入档案后开始新任务即可测试。

尚未接入在线大模型、自动评测/计划、账号云备份、语音、真人数字人或摄像头教学。测试档案不是登录账号；请仅使用测试内容。卸载会删除本地记录，当前不提供导出或云备份。

## 后续更新

后续此渠道保持相同开发签名和包名，版本代码递增。请从本仓库下载；其他机器或 CI 的临时签名构建不保证能够覆盖安装。当前应用没有内置更新入口，暂时手动下载新版本。

`latest.json` 是发布元数据，不代表当前应用会自动检查更新。开发预发布请使用具体版本页或全部版本页，不依赖 GitHub 的 `/releases/latest`。
